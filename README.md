AI Blog Series – Capstone 46

AI in Education: Smarter Learning, Human Thinking

Project Overview

This project compares manual blog writing with AI-assisted blog writing to understand how Artificial Intelligence affects writing speed, readability, originality, and quality.

Objectives

- Create a manual blog and an AI-assisted blog.
- Compare writing time and readability.
- Perform plagiarism and readability checks.
- Verify important claims using trusted sources.
- Explore responsible AI use in education.

Project Contents

- Manual Blog
- AI-Assisted Blog
- Plagiarism and Readability Checks
- Educational Poster
- LinkedIn and Instagram Promotion Posts
- Manual vs AI Comparison
- Prompt Library
- Verification Report
- Before-and-After Analysis
- Final Demo Presentation Plan

Tools Used

- ChatGPT
- Claude
- Canva
- Perplexity

Key Findings

- Estimated manual drafting time: 150 minutes.
- Estimated AI-assisted drafting time: 40 minutes.
- Estimated time saved: approximately 73%.
- Both blog versions received the same quality score in the project comparison.

Responsible AI

This project highlights the importance of fact-checking, privacy, academic honesty, human review, and independent thinking when using AI tools.

Conclusion

AI can help improve writing efficiency and organise ideas. However, human judgement, accuracy checks, and responsible AI use remain essential.
